Cómo se calcula la relevancia

Cada investigación recibe una cercanía de 0 a 1 en cada variable. El puntaje es el promedio ponderado de las variables con datos; las que no tienen datos no cuentan, y se informa la cobertura. El orden final ajusta el puntaje por la cobertura, para no poner arriba investigaciones de las que casi no se sabe nada.

Oxígeno: 1 dentro del rango, pierde 0,1 por cada punto porcentual de distancia. Presión: 1 dentro del rango, llega a 0 al doble o a la mitad. Material: 1 misma categoría, 0,5 misma fase. Gravedad: los datos de PSI son de microgravedad o de tierra; para gravedad lunar o marciana ambos solo acotan el comportamiento.
